## v2.0 — 纯 Office.js 路线

把 .pptx 处理从「server 端 JSZip 解包 → 改 OOXML → 重新打包」改成「直接调
Office.js 在 PowerPoint 进程内读写」。server 缩到 ~75 行纯静态文件服务。
净 -611 行（252 增 / 863 删），.app 从 540K 缩到 436K（-19%）。

### 关键修复

1. **`Adjustments.value` 单位是 0~1，不是 0~50000**（`3a92e17`）
   - Mac LTSC dialog 里 `get(0).value` 返回 0~1 的小数比例（OOXML 值 ÷ 50000）
   - 旧代码 `ADJ_SCALE = 100000` → 0.17183 / 100000 * 7.46 ≈ 0，圆角全显示成 0.00
   - 改 `ADJ_SCALE = 1` 后 `0.17183 * 7.46 = 1.28cm` 正确

2. **macOS PowerPoint 不会弹「文件外部被修改」对话框**
   - 之前必须服务端 .pptx 改完让 PPT 重新加载，触发 prompt
   - 切到 Office.js 后完全 in-memory，PPT 自动更新视图，不弹框

3. **`.app` 启动器总是 `mkdir -p` wef 目录**（`be7e6b1`）
   - PowerPoint Cmd+Q 会回收 container 目录，old manifest 失效
   - 启动器每次都重新拷新 manifest

4. **customProperty 在 dialog 不可用 → 降级 localStorage**（`e2fbfae`）
   - Mac LTSC dialog 上下文里 `customProperties` API 返回 undefined
   - 锁存到 localStorage（key = `radius_in_ppt_locks_v2`）
   - 代价：跨机器不持久

### 关键功能

- 多选支持：`getSelectedShapes()` + 逐个 set
- 实时选区变化：`DocumentSelectionChanged` event 自动 refresh
- 非圆角矩形检测：`adjustments.count`（roundRect=1，其他=0）+ UI 标记
- 调试面板：底部 `<details>` 显示 raw Office.js 值
- 重新读按钮：event 没触发时手动 refresh

### 踩坑过程

调试面板最终打出来的 `adjustments.get(0).value = 0.17183` 是整个 bug 的
关键线索。中间误以为是 `load('value')` 没调（试了 → 报 `load is not a function`
→ 说明 `get(0)` 返回的是 ClientResult 不是 ClientObject）→ 回退到直接 `.value`
→ 看到 0.17183 这个非 0 也非 50000 量级的值 → 意识到单位不对 → 改 ADJ_SCALE=1。
