# R角调整 · Native

macOS PowerPoint 原生加载项 · v1.4.0

把圆角编辑、父子关系和网格布局放进 PowerPoint 功能区。安装 `.ppam` 后，从顶部「R角调整 · Native」使用；日常操作不需要单独启动应用或服务器。

## 功能

- **批量调整圆角**：按厘米或短边百分比设置，支持读取当前值、常用预设和多选。厘米对所有目标写入相同半径；百分比按每个形状各自的短边计算。半径限于短边的一半，允许设为 0。
- **防误触**：保护状态随选区显示。选区中有受保护形状时，加载项会禁用相应写入，并由写入逻辑再次检查保护状态。保护只限制本加载项修改圆角。
- **即时微调**：半径框旁的上下箭头按当前单位每次增减 0.1，并立即应用。
- **父子关系**：在同一页为圆角矩形指定一个父对象并绑定多个子对象。可查看、定位和解除成员；编号预览在临时副本中进行，不会写入原稿。
- **网格布局与圆角联动**：按行列排列子对象，设置厘米边距和间距；子圆角可跟随父圆角、按边距内缩，或关闭联动。关系和布局设置保存在文稿中。
- **快速自检**：从功能区运行算法及业务检查。检查在临时文稿中执行，结束后关闭，不保存测试文稿。

## 安装

1. 解压 `dist/RadiusInPptNative-mac.zip`，将 `.ppam` 放到长期保留的位置。默认目录为 `~/Library/Application Support/RadiusInPptNative`。可运行压缩包内的文件准备脚本，也可手动复制。
2. 在 PowerPoint 中打开「工具 → PowerPoint 加载项」，添加该 `.ppam` 并保持勾选。按 Office 提示允许此加载项的宏。
3. 确认顶部出现「R角调整 · Native」。完全退出 PowerPoint（Cmd+Q）后重新打开，确认加载项仍在。

文件准备脚本只复制文件，不会替 PowerPoint 注册加载项。更新时先保存文稿并完全退出 PowerPoint，再替换安装文件并重新打开验证。不要从会被重建的 `dist` 目录加载插件。完整步骤见[安装说明](native/INSTALL.txt)。

## 日常使用

选中一个或多个圆角矩形，在功能区输入厘米值或百分比，再点「应用R角」。也可以读取当前值、使用预设，或点上下箭头立即微调。多选时百分比按各形状自己的短边换算。

建立布局时，先选中父圆角矩形并点「设为父对象」，再选子对象并点「绑定子对象」。之后选中关系中的父或子，设置行列、边距、间距和子圆角模式，再应用布局。旋转或翻转的组合/成员不支持布局及圆角联动；若任一子对象受保护，整批布局或联动写入会被拒绝。

## 支持范围与限制

- 当前交付为 PowerPoint VBA 加载项 `.ppam`，不是独立应用。安装后由 PowerPoint 加载。
- 设计目标为 Office LTSC Standard for Mac 2021。当前宿主验收覆盖 PowerPoint 16.113.4/26100421；目标版本 16.111 尚待单独验证。
- 修改组合内圆角或保护时，请选中完整顶层组合。父子关系操作支持组合内成员。
- 防误触阻止加载项写入，不会撤销用户直接拖动 PowerPoint 黄色手柄或调整形状尺寸造成的变化。
- 实时固定圆角、样式刷、自定义预设库和历史记录尚未迁移到原生版本。


安装后的加载项不依赖 Node 或 Python。测试清单和覆盖范围见[test/README.md](test/README.md)。原生架构、限制和验收记录见[原生方案](plans/ribbon-vba-mac.md)、[项目日志](LOG.md)及[v1.4.0 变更记录](changelogs/v1.4.md)。旧 Office.js 实现仅保留作迁移对照，见[历史文档](README.taskpane.md)。
