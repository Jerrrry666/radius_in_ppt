# R 角调整 — 功能路线图（v1.1+）

> 立项：2026-07-23
> 状态：待用户拍板优先级 & 实施批次
> 基础版本：v1.0（task pane · cm/% 双单位 · 多选 · shape.tags 锁定 · session 内存 history）

---

## 1. 背景

v1.0 解决了"单个 / 多个圆角矩形精确设 R 角"的最小可用问题。

但用户的真实使用场景（**学术 PPT**）会反复出现两类更复杂的需求：

- **嵌套关系**：多个圆角矩形内外层堆叠时，边缘到边缘的距离希望恒等
- **批量一致性**：一组圆角矩形要 R 角统一

这份 roadmap 把这两类需求 + 周边优化拆成可分批交付的功能，每条都标了优先级和验收标准。

---

## 2. 调研摘要

来自设计理论 / 同类工具 / 学术 PPT 实际场景的三个关键观察：

### 2.1 设计理论

- 圆角半径占短边的 **0.1 ~ 0.3** 视觉效果最好
- 元素越大 R 角相对越小、越小 R 角相对越大 → 视觉权重才一致
- 85% 用户更喜欢圆角 UI；圆角按钮点击率比直角高 **20%**
- 绝对值不重要，**比例**才重要

### 2.2 同类工具（iSlide 等 PPT 插件）

用户最高频操作：

- 批量统一 R 角
- 形状转换（直角 ↔ 圆角）
- 参数化批量操作（设计 tab 风格）

### 2.3 嵌套等距的数学原理

外层 w×h R=r，内层等距缩进 d 后的形状应该是：

- 新尺寸：`(w - 2d) × (h - 2d)`
- 新 R 角：**`r - d`**（保证所有方向边缘距离恒等于 d，包括角部）

如果内层 R 角没自动调整到 `r - d`，角附近距离会从 `d` 渐变到 `√2 × d`，视觉上"角部变挤"。

这是用户提的核心痛点的几何本质。

## 3. 功能清单

### 🔥 核心（P0）

#### 3.1 嵌套等距缩进 R 角

**背景**：用户 v1.1+ 首要诉求。PPT 论文配图里大量背景框 + 引用框 + 子项框嵌套场景。

**功能定义**：
- 选中 **2 个** 圆角矩形（一个外层、一个内层）→ 输入「边距 d」→ 内层 R 角自动设为 `外层R - d`，同时把内层尺寸调整为 `(w-2d) × (h-2d)` 居中
- 选 3+ 个：按选区里的 z-order 自动取最外 / 次外为「外层 / 内层」一对，剩下忽略
- 支持 cm 和 % 两种单位（% 参考外层短边）

**数学保证**：
- 内层 R = `max(0, 外层 R − d)`（不能为负）
- 内层尺寸不能比 `2d` 还小（要给圆角留位置），否则提示

**验收标准**：
- 选 12×8cm R=1cm 外层 + 7×3cm R=0.3cm 内层，间距 2cm → 内层自动变 8×4cm R=0cm（最大圆角 = 短边一半 → 0 + 2 = 2 正好），且角部边缘距 = 2cm
- 圆角小到 `R - d < 0` 时给出 toast 警告并 clamp

**实现要点**：
- 选区判断用 z-order（PowerPoint 的 `getSelectedShapes()` 不保证 z-order，需要用 `getParentShape()` 或 `getZOrderPosition()` 试）
- 计算 + 写 adjustments 走现有 pipeline（`newAdj = (targetCm / minSideCm) * ADJ_SCALE`）
- 内层尺寸调整走 `sh.width.set(newW)` / `sh.height.set(newH)` + `sh.left/top.set()` 居中

---

#### 3.2 R 角预设库

**背景**：学术 PPT 风格统一是刚需。一份 PPT 几十个圆角框，R 角要一致才好看。每次手输太慢。

**功能定义**：
- 5 个用户自定义预设槽位：纯内存，session 内保存
- 命名（如"标题框"、"正文框"、"小标签"）+ 数值（cm / % 都行）
- 选中圆角矩形 → 点预设 → 一键应用
- 槽位可重命名 / 覆盖 / 清空

**验收标准**：
- 5 个槽位可重命名
- 命名 + 数值都显示
- 点击即应用

**实现要点**：
- 内存数组 `{ name, value, unit }[]`
- HTML 渲染：每行「名称 | 数值 | 按钮」
- 不跨 session（v1.0 history 也是 session 内存，保持一致）
- v2 升级时再考虑持久化（用 shape.tags 挂在一个隐藏 helper 形状上）

---

#### 3.3 R 角"样式刷"

**背景**：统一一组圆角矩形 R 角是 iSlide 类工具最高频操作之一。

**功能定义**：
- 一个开关按钮：「吸取 R 角」（像格式刷）
- 点「吸取」→ 选源形状 → task pane 记下 R 角 + 单位
- 然后切到目标形状 → R 角自动应用
- 或者支持「双击吸取」进入「连刷模式」，连点多个形状都套用

**验收标准**：
- 吸取消除状态保留到切走或再点一次「取消吸取」
- 目标不是圆角矩形 → 跳过 + 警告
- 跨页 PPT 也能用

**实现要点**：
- 状态机：`idle | sourcing | brushing`
- 切形状触发 `DocumentSelectionChanged` → 自动 apply（如果 brushing）
- 与锁定功能可叠加：先刷 R 角，再锁定保持

### ⭐ 增强（P1）

#### 3.4 history 跨 session 持久化

**背景**：v1.0 history 纯内存，关掉 PPT 就没。

**功能定义**：
- 用 **shape.tags** 在当前选区里挑一个圆角矩形挂 JSON 串（key = `radiusHistory_v1`，value = `[{value, unit, ts, shapeName}]`）
- 启动 task pane 时读这个 tag → 还原 history
- 5 条上限不变

**验收标准**：
- 选 1 个圆角矩形 → 应用 3 次不同 R 角 → 退出 PPT → 重开 PPT → 选中同一个形状 → history 还在
- 选不同形状 → history 隔离（每个形状自己的 history）

**实现要点**：
- 注意 tag key 唯一性 + JSON 序列化
- Mac LTSC 兼容（`shape.tags` 已验证 work）

---

#### 3.5 黄金比例 R 角建议

**背景**：用户没设计经验时，10% / 20% / 30% 短边比例是好默认值。

**功能定义**：
- 选中圆角矩形 → task pane 显示「建议 R 角」区，给 3 个一键按钮：10% / 20% / 30%（按短边算）
- 显示具体数值预览（cm）

**验收标准**：
- 切换单位（cm ↔ %）时建议值同步换算
- 短边极小（< 1cm）时提示

---

#### 3.6 批量"按视觉比例"统一

**背景**：一组大小不一的圆角矩形，绝对 R 角统一 → 小的看着很"硬"、大的看着很"软"。按各自短边的固定百分比统一才合理。

**功能定义**：
- 选中多个圆角矩形 → 切到「按比例」模式 → 输入「短边的 X%」→ 各自按自己短边算
- 比如 3 个 5cm、10cm、20cm 短边，统一 20% → 1cm、2cm、4cm

**验收标准**：
- 与 v1.0 绝对值模式互不冲突（用户切单位时保留输入框值）
- 状态卡显示「按比例」标记

---

#### 3.7 直角矩形一键转圆角矩形

**背景**：PPT 画好普通矩形才发现要圆角 → 只能删了重画圆角矩形再调大小，麻烦。

**功能定义**：
- 选中**非圆角矩形**（adjustments.count = 0）→ 显示「转换为圆角矩形」按钮 → 点一下：convert + 应用当前 R 角

**验收标准**：
- 转完后立刻进入普通 R 角编辑流程
- 不影响其他属性（大小、位置、颜色、文本）

**实现要点**：
- Mac LTSC 验证过 `shape.toShape()` / `Shape.convertToShape` 是否可用
- 备选：复制原 shape → 删原 shape → 插入 roundRect（丑，不推荐）

---

### 💡 锦上添花（P2）

#### 3.8 快捷键

task pane 内：数字键 0–9 直对应 10 个 R 角值（cm），快速应用。

#### 3.9 R 角滑块预览

大图实时预览圆角矩形效果，拖滑块调 R 角。

#### 3.10 暗色模式适配

task pane 当前是亮色背景，macOS 暗色用户看着刺眼。适配 `@media (prefers-color-scheme: dark)`。
